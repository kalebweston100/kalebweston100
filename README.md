## Projects

These repos span about six years. I've kept the older ones close to how I
originally wrote them, with notes on what I'd do differently now, so the
progression is visible.

| Year | Project | What it shows |
|------|---------|---------------|
| 2026 | [**nft-integrity-framework**](https://github.com/kalebweston100/nft-integrity-framework) | Solidity framework for ERC-20/721/1155 tokens with a non-bypassable transfer pipeline, external `CALL`-only hooks, and on-chain verifiable NFT flags. Foundry unit + invariant tests, Slither, CI. |
| 2026 | [**Decentralized-Exchange**](https://github.com/kalebweston100/Decentralized-Exchange) | AMM DEX in two iterations: dynamic fees, tiered LP staking, and conditional orders with a Next.js/wagmi frontend, then a multi-token ETH-hub redesign with permissionless listing and a rug-pull lock. |
| 2023 | [**Tuby**](https://github.com/kalebweston100/Tuby) | C + PortAudio experiment: record audio, fit a distortion model with gradient descent, and apply it to live input. |
| 2021–23 | [**Wallflower-App**](https://github.com/kalebweston100/Wallflower-App) | Android app, formerly on Google Play: serverless, RSA-encrypted chat between nearby phones over Wi-Fi Direct. |
| 2020 | [**Java-Server**](https://github.com/kalebweston100/Java-Server) | Multi-client chat server from scratch: raw sockets, a hand-rolled protocol and JSON encoder, a Swing client, and MySQL. |

**Languages & tools:** Solidity · Java · TypeScript · C · Foundry · Hardhat ·
OpenZeppelin · Next.js · Android · MySQL
